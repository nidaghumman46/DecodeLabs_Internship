# SQL Data Analysis Project

## Overview

This project focuses on analyzing an e-commerce dataset using SQL queries. The objective is to extract meaningful business insights through data filtering, sorting, grouping, and aggregation techniques.

## Project Objectives

- Perform data exploration using SQL
- Analyze sales performance
- Identify top-selling products
- Evaluate payment methods
- Analyze order status distribution
- Generate business insights from transactional data

## Dataset Information

The dataset contains e-commerce order records with the following fields:

- OrderID
- Date
- CustomerID
- Product
- Quantity
- UnitPrice
- ShippingAddress
- PaymentMethod
- OrderStatus
- TrackingNumber
- ItemsInCart
- CouponCode
- ReferralSource
- TotalPrice

## SQL Concepts Used

- SELECT
- WHERE
- ORDER BY
- GROUP BY
- COUNT()
- SUM()
- AVG()
- LIMIT

## Analysis Performed

### 1. Data Exploration
- View all records
- Display selected columns

### 2. Sales Analysis
- Total Sales
- Average Order Value
- Top 10 Products by Sales

### 3. Product Analysis
- Product-wise Sales
- Product-wise Quantity Sold

### 4. Payment Analysis
- Orders by Payment Method
- Sales by Payment Method

### 5. Order Status Analysis
- Shipped Orders
- Cancelled Orders
- Order Status Distribution

### 6. Marketing Analysis
- Referral Source Performance
- Coupon Code Usage Analysis

## Tools Used

- SQL

- Calculated total revenue generated from all orders.
- Identified the highest-selling products.
